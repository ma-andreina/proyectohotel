# 📋 Sistema Web Hotel Índigo 🏨
# Descripción del Proyecto
Sistema Web Integral para la Gestión de Reservas y Operaciones del Hotel Índigo

Es una plataforma completa de gestión hotelera desarrollada para optimizar las operaciones diarias de un hotel de categoría media-alta. Este sistema centraliza todos los procesos críticos del hotel, desde la gestión de reservas hasta el control de inventario y la atención al cliente, proporcionando una experiencia fluida tanto para los huéspedes como para el personal del hotel.

# 🎯 Problema que Resuelve
Antes de este sistema, el Hotel Índigo enfrentaba desafíos operativos significativos:
Procesamiento manual de reservas con un 15% de errores
Falta de visibilidad en tiempo real del estado de habitaciones
Comunicación ineficiente entre departamentos
Control manual de inventario con pérdidas frecuentes
Experiencia del cliente limitada sin autoservicio digital

# ✨ Características Principales
# 🛏️ Módulo de Reservas
Reserva de habitaciones con disponibilidad en tiempo real
Sistema de validación automática (fechas, capacidad, superposición)
Reserva de mesas en el restaurante con preferencias especiales
Reserva de salones para eventos con control de equipamiento
Códigos de confirmación únicos para cada reserva
Email automático de confirmación transaccional

# Políticas inteligentes de cancelación y modificación
# 👥 Módulo de Usuarios y Roles
Sistema de autenticación seguro con JWT
Gestión de roles: Administrador, Recepcionista, Cajero, Supervisor, Cliente
Perfiles personalizables por tipo de usuario
Historial completo de actividad del usuario
Sistema de permisos granular por módulo y acción

# 📊 Dashboard Administrativo
Visión en tiempo real de ocupación y disponibilidad
Alertas automáticas de checkout y stock bajo
Reportes ejecutivos con gráficos interactivos
Calendario integrado de todas las reservas
Métricas de rendimiento (ocupación, ingresos, etc.)

# 📦 Módulo de Inventario
Control completo de insumos y productos
Alertas automáticas de stock bajo y vencimientos
Sistema de reposición con órdenes de compra
Historial de movimientos de inventario

# 🍽️ Módulo de Restaurante y Eventos
Menús digitales con gestión de platos
Reservas de mesas con preferencias alimenticias
Gestión de eventos con control de equipamiento

# Sistema de disponibilidad por horarios
# 📱 Landing Page Informativa
Diseño responsive optimizado para todos los dispositivos
Galería multimedia de alta calidad
Información completa del hotel (habitaciones, servicios, contacto)
Formulario de contacto integrado
Mapa de ubicación con Google Maps

# 🛠️ Tecnologías Utilizadas
# 🔧 Backend
Framework: Django 4.2 + Django REST Framework
Lenguaje: Python 3.9+
Autenticación: JWT + Token Authentication
Base de Datos: postgresql

# 🎨 Frontend
Tecnologías Base: HTML5 Semántico, CSS3, JavaScript ES6+
Framework: React 18 (con opción Vanilla JS)
Diseño: Mobile-first, responsive
